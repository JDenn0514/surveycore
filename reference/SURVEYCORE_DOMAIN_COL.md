# Internal Domain Column Name Constant

The name of the logical column added to `@data` by
[`filter()`](https://rdrr.io/r/stats/filter.html) (from `surveytidy`) to
mark domain membership. Exposed here so that sibling packages
(`surveytidy`, `surveyweights`) can reference it without using `:::`.

## Usage

``` r
SURVEYCORE_DOMAIN_COL
```

## Format

An object of class `character` of length 1.
