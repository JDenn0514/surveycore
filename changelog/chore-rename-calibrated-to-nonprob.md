**Branch:** `chore/rename-calibrated-to-nonprob`
**Date:** 2026-03-11

## Summary

Renames `survey_calibrated` → `survey_nonprob` and `as_survey_calibrated()` →
`as_survey_nonprob()` throughout the codebase. The old name was confusing:
"calibrated" sounds like a post-processing step applied to a probability sample
(e.g., raking, post-stratification), not a distinct design type for
non-probability samples. `survey_nonprob` is shorter, consistent with the
existing class naming pattern (`survey_srs`, `survey_taylor`, etc.), and
matches the standard abbreviation used in the field.

This is a pure rename — no behavioral changes.
