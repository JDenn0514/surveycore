# Changelog: docs/corr-inline-span

**Branch:** `docs/corr-inline-span`
**Status:** Complete
**Date:** 2026-09-06

## Summary

Closes #230. `devtools::document()` printed a warning on every run.

DESCRIPTION sets `markdown = TRUE`, and roxygen2 8.1.0 reads a backtick span
that starts with `r ` as inline knitr R code. One sentence in `get_corr()`
carried the span `` `r = NA` ``. Roxygen tried to evaluate `r = NA` as R
code, failed to parse it, and warned.

The sentence now reads "an `r` of `NA` and an `n` of `0`", so no span starts
with `r `. The man page states the same behaviour as before.

**No behaviour changes.** One line of roxygen text and the regenerated `.Rd`.
