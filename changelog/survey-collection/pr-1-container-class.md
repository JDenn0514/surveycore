# feat(classes): add survey_collection container class

**Date**: 2026-04-21
**Branch**: feature/survey-collection-class
**Plan**: survey-collection (PR 1)

## Changes

- Add `survey_collection` S7 class holding an ordered, uniquely-named list
  of `survey_base` objects in `@surveys`. Validator enforces: non-empty,
  fully named (no `""` / `NA`), unique names, and every element inherits
  `survey_base`. Class does NOT inherit `survey_base` (spec §2).
- Add `as_survey_collection(...)` constructor. Accepts named arguments
  (`wave1 = d1`) and bare symbols (`d1` auto-named to `"d1"`). Duplicate
  names are repaired by appending `_1`, `_2`, … via the left-to-right
  algorithm in spec §3.3.1; existing names are never modified. Emits
  `surveycore_warning_collection_duplicate_name_repaired` with the
  rename mapping.
- Add `add_survey(.collection, ...)` mutator. Returns a new collection
  with the appended surveys; original is unchanged. Uses `.collection`
  as the formal name to avoid collision with user-supplied `x = …` in
  `...`. Calling with no new surveys returns `.collection` unchanged.
- Add `remove_survey(x, name)` mutator. Errors with
  `surveycore_error_collection_name_not_found` if any requested name is
  missing; errors with `surveycore_error_collection_empty` (via the
  validator) if removal would leave the collection empty.
- Add four S7 method registrations: `print`, `[[`, `length`, `names`.
  `print` shows up to 20 rows with `... and N more` abbreviation and
  formats each line as `"name": <class>, <rows> rows, <vars> variables`.
- Add `test_collection_invariants()` helper to `helper-test-data.R`
  asserting all four invariants plus the non-inheritance requirement.
- Add six new error/warning classes to `plans/error-messages.md`:
  C1 `surveycore_error_collection_empty`,
  C2 `surveycore_error_collection_bad_element`,
  C2a `surveycore_error_collection_duplicate_name`,
  C3 `surveycore_error_collection_unnamed_expr`,
  C4 `surveycore_error_collection_name_not_found`,
  C8 `surveycore_warning_collection_duplicate_name_repaired`,
  plus the existing `surveycore_error_not_survey_collection` reused by
  mutator type checks.
