# feat(constructors): add repweights support to as_survey_nonprob()

**Date**: 2026-05-19
**Branch**: feature/nonprob-bootstrap-class
**Plan**: nonprob-bootstrap-variance (PR 1)

## Changes

- Extend `as_survey_nonprob()` with six new arguments: `repweights`,
  `type`, `scale`, `rscales`, `mse`, and `reference_sample`. When
  `repweights` is supplied, constructor resolves replicate weight columns
  via `tidyselect::eval_select()`, validates them (≥2 columns, type
  `"bootstrap"`, non-NA/non-negative `rscales`), and stores all five
  keys (`repweights`, `type`, `scale`, `rscales`, `mse`) in
  `@variables`. When `repweights = NULL`, all five keys are stored as
  `NULL`. `scale` defaults to `1/R`; `rscales` defaults to
  `rep(1, R)`.
- Add `reference_sample` property to `survey_nonprob` S7 class. Type
  checking is Layer 3 (constructor `cli_abort()`); no S7 validator
  change. Provenance checks fire when a reference sample is supplied:
  errors if not a `survey_nonprob`, if not `type = "bootstrap"`, or if
  `R` counts mismatch.
- Extend `.validate_rscales()` to detect NA, non-numeric, and negative
  values, firing `surveycore_error_rscales_na` in all three cases. This
  check applies to both `as_survey_nonprob()` and `as_survey_replicate()`
  paths.
- Extend `test_invariants()` in `helper-test-data.R`: for
  `survey_nonprob` objects, assert all five repweight keys are present
  in `@variables` (values may be `NULL`).
- Add eight new error/warning classes to `plans/error-messages.md`:
  NB-1 `surveycore_error_type_invalid`,
  NB-2 `surveycore_warning_nonprob_srs_fallback`,
  NB-3 `surveycore_error_repweights_single`,
  NB-4 `surveycore_warning_domain_replicates_na`,
  NB-5 `surveycore_error_reference_sample_nonprob`,
  NB-6 `surveycore_error_provenance_not_bootstrap`,
  NB-7 `surveycore_error_provenance_R_mismatch`,
  NB-8 `surveycore_error_rscales_na`.
