# feat(metadata): add set_sata() and extract_sata()

**Date**: 2026-04-16
**Branch**: feature/set-extract-sata
**Phase**: Phase sata-metadata

## Changes

- Add `set_sata()` — unified setter to mark variables as select-all-that-apply
  (SATA) on a survey design object or a plain data frame. Uses a simplified
  two-convention pattern (tidy-select `...` or character `variable` argument)
  because SATA is a uniform flag rather than per-variable content. Setting
  `sata = FALSE` removes the flag; setting it on an already-flagged variable
  is idempotent.
- Add `extract_sata()` — getter that returns SATA status in
  `"named_vector"` (default), `"list"`, or `"data_frame"` formats. Default
  `fill = FALSE` yields a dense view (unmarked variables reported as `FALSE`);
  `fill = NULL` yields a sparse view (only flagged variables).
- Add `.format_logical_result()` internal helper in `R/core-metadata.R` for
  formatting the named logical vector returned by `extract_sata()`.
- Add three new error classes to `plans/error-messages.md` (S-1, S-2, S-3):
  `surveycore_error_sata_ambiguous_input`, `surveycore_error_sata_no_vars`,
  and `surveycore_error_sata_not_logical`. Existing
  `surveycore_warning_var_not_found` is reused for skipped-variable warnings.
