# feat(metadata): add classify_question_type()

**Date**: 2026-04-16
**Branch**: feature/classify-question-type
**Phase**: Phase sata-metadata

## Changes

- Add `classify_question_type()` — classifies a set of requested variables
  into `"single"`, `"sata"`, or `"battery"` by grouping them on shared
  `question_preface` metadata and honoring per-variable `sata` flags set via
  `set_sata()`. Group numbers are assigned sequentially by first appearance
  of each preface in the input. Supports the same dual interface used
  elsewhere in the metadata API (`...` tidy-select or `variable` character
  vector). Works on survey design objects (reads from
  `@metadata@question_prefaces` and `@metadata@sata`) and plain data frames
  (reads from `attr(col, "question_preface")` / `attr(col, "sata")`).
- Update `.extract_var_meta()` in `R/analysis-helpers.R` to include a
  `sata = TRUE/FALSE` key. This surfaces SATA status through the nested
  `.meta$x` / `.meta$group` objects that every `get_*()` analysis function
  attaches to its result, so downstream code (export functions, visual
  rendering) can read SATA status without re-querying the design.
- Add four new error/warning classes to `plans/error-messages.md` (D-1
  through D-4): `surveycore_error_detect_ambiguous_input`,
  `surveycore_error_detect_no_vars`, `surveycore_warning_sata_no_preface`,
  `surveycore_warning_sata_mixed_group`. Existing
  `surveycore_error_not_survey_or_df` and `surveycore_warning_var_not_found`
  are reused.

## Behavior notes

- A variable marked SATA whose `question_preface` is not shared with any
  other requested variable is classified as `"single"` with a
  `surveycore_warning_sata_no_preface` warning (the SATA flag alone cannot
  make a lone variable a SATA set).
- When a `question_preface` group contains mixed SATA flags (some `TRUE`,
  some not), the entire group is classified as `"sata"` and a
  `surveycore_warning_sata_mixed_group` warning is issued — this usually
  means the analyst missed a variable in a prior `set_sata()` call.
- When all requested variables are absent from `x`, a zero-row tibble with
  the expected columns is returned (after the missing-variable warning).
