# refactor(analysis): add shared helpers for nested meta structure and group label conversion

**Date**: 2026-02-26
**Branch**: feature/analysis-label-meta-helpers
**Phase**: Phase 1

## Changes

- Add `.extract_var_meta()` helper: returns a `list(variable_label, question_preface, value_labels)` for any variable; checks `@metadata` first, falls back to haven column attributes; surfaces `levels()` as named integer `value_labels` for factor columns
- Add `.build_group_meta()` helper: builds the nested `group` named list used in the new `.meta` structure, returning `list()` for ungrouped designs
- Add `.apply_group_labels()` helper: converts coded group columns in `group_combos` data frames to labelled factors; respects `label_values` gate; handles haven-labelled columns (code-order factor levels) and plain R factors (original level order)
- Add `FREQS_META_KEYS`, `MEANS_META_KEYS`, `TOTALS_META_KEYS`, `CORR_META_KEYS`, `QUANTILES_META_KEYS`, `RATIOS_META_KEYS` constants with new nested key names (`"group"`, `"x"`, etc.) alongside existing flat constants (old constants kept until subsequent PRs migrate each function)
- Update `meta()` documentation to describe the new nested `.meta` structure (`group`, `x`, `probs`, `method`, `numerator`/`denominator` for `get_ratios`)
- Add 22 tests for the three new helpers covering all specified cases: all-NULL return, `@metadata` precedence over haven attrs, factor level extraction, empty group vars, multi-group, haven label conversion, factor column conversion, `label_values = FALSE` gate, multi-column mixed labelling
- Update `.gitignore` to exclude `SOPs/` directory
