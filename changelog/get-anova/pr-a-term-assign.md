# feat(classes): add @term_assign property to survey_glm_fit

**Date**: 2026-04-18
**Branch**: feature/survey-glm-fit-term-assign
**Plan**: get-anova (PR A)

## Changes

- Add `@term_assign` integer-vector property to the `survey_glm_fit` S7
  class, with default `integer(0)` and validator type enforcement via
  `S7::class_integer`.
- Populate `@term_assign` inside `survey_glm()` from
  `attr(model.matrix(fit_), "assign")` so the term-to-column map survives
  serialization (required by `get_anova()`'s serialization-safe Wald path,
  spec §3.3.1).
- Extend the class-level roxygen block with a slot description for
  `term_assign` matching the existing slot-description style.
- Add TDD tests for the new property: default value, validator rejection
  of non-integer input, population from `model.matrix()`, and survival
  across `saveRDS()` round-trip when `@fit_` is stripped.

## Files Modified

- `R/glm.R` — add `term_assign` property + roxygen slot description;
  pass `term_assign = as.integer(attr(stats::model.matrix(fit), "assign"))`
  into the `survey_glm_fit()` constructor call inside `survey_glm()`.
- `tests/testthat/test-glm.R` — add four test blocks covering the
  property default, validator type check, constructor population, and
  `saveRDS()` survival.
- `man/survey_glm_fit.Rd` — regenerated by `devtools::document()` to
  render the new slot description.
