# Design: Add `ca_api_2000` Dataset to surveycore

**Date:** 2026-06-08
**Status:** Approved

---

## Summary

Add the California Academic Performance Index two-stage cluster sample (`apiclus2`
from the `survey` package) to surveycore as `ca_api_2000`. The dataset will be used
in the `getting-started.Rmd` vignette to demonstrate two-stage cluster survey design.

---

## Source Data

- **Origin:** `survey::apiclus2` — a two-stage cluster sample from the 2000
  California Academic Performance Index (API) study.
- **Population:** 6,194 California public schools.
- **Sample:** 126 schools from 40 districts. Districts were sampled at the first
  stage (PSU); schools within selected districts at the second stage (SSU).
- **Load:** `data(api, package = "survey")` — no download needed since `survey`
  is already in `Suggests`.

---

## Prepare Script: `data-raw/prepare-ca-api-2000.R`

Steps in order:

1. **Load** `apiclus2` via `data(api, package = "survey")`.

2. **Drop `flag`** — entirely `NA` across all 126 rows; no analytical value.

3. **Convert 6 factor columns to integer.** Consistent with all other surveycore
   datasets (GSS, NHANES, ANES), categoricals are stored as plain integers with
   `labels` attributes — not R factors.

   | Column | Type | Labels |
   |--------|------|--------|
   | `stype` | Factor `"E","H","M"` | `c(Elementary = 1, High = 2, Middle = 3)` |
   | `sch.wide` | Factor `"No","Yes"` | `c(No = 0, Yes = 1)` |
   | `comp.imp` | Factor `"No","Yes"` | `c(No = 0, Yes = 1)` |
   | `both` | Factor `"No","Yes"` | `c(No = 0, Yes = 1)` |
   | `awards` | Factor `"No","Yes"` | `c(No = 0, Yes = 1)` |
   | `yr.rnd` | Factor `"No","Yes"` | `c(No = 0, Yes = 1)` |

   Binary indicators use `0/1` (not `1/2`) for semantic clarity.

4. **Attach `label` attributes** to all 39 columns. The source `var.labels`
   attribute on `apiclus2` covers most columns; the ~10 blank entries are
   filled manually:

   | Column | Label |
   |--------|-------|
   | `stype` | `"School type"` |
   | `api00` | `"API score 2000"` |
   | `api99` | `"API score 1999"` |
   | `target` | `"API growth target"` |
   | `growth` | `"API score change (api00 - api99)"` |
   | `yr.rnd` | `"Year-round school"` |
   | `pct.resp` | `"Percent of parents responding to survey"` |
   | `pw` | `"Sampling weight (inverse probability of selection)"` |
   | `fpc1` | `"First-stage FPC (total districts in frame = 757)"` |
   | `fpc2` | `"Second-stage FPC (schools in the selected district)"` |

5. **`clean_names()`** — converts dot-separated names to snake_case:
   `sch.wide` → `sch_wide`, `avg.ed` → `avg_ed`, `api.stu` → `api_stu`, etc.

6. **Save** with `usethis::use_data(ca_api_2000, overwrite = TRUE)`.

## Documentation: `R/data.R`

New entry `"ca_api_2000"` following the existing format. Key sections:

- **`@format`**: 126 rows, 39 variables. Lists all columns with type and
  description; groups design variables (`dnum`, `snum`, `pw`, `fpc1`, `fpc2`)
  first.
- **`@details`**:
  - Survey design block showing `as_survey()` call with `ids = c(dnum, snum)`
    and `fpc = c(fpc1, fpc2)`.
  - Missing values note: several columns (`acs_k3`, `acs_46`, `acs_core`,
    `pct_resp`) have `NA` for schools where values are inapplicable.
  - Metadata note: all columns carry `"label"` attributes; the 6 categorical
    columns additionally carry `"labels"` attributes.
  - Note that this is the same dataset as `apiclus2` in the `survey` package,
    reformatted to surveycore conventions.
- **`@source`**: Lumley's `survey` package (primary); California Department of
  Education (original data).
- **`@examples`**: `head()` call, `as_survey()` design creation, and one
  `attr()` label inspection.
