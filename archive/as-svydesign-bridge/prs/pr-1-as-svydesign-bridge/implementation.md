## What was implemented

- `as_svydesign()` gains a fourth dispatch branch, after the `survey_twophase`
  branch and before the `else`. It tests
  `S7::S7_inherits(x, survey_nonprob)`, then routes on
  `!is.null(x@variables$repweights)`: the replicate shape to
  `.as_svydesign_replicate()`, the plain shape to `.as_svydesign_taylor()`.
  Both the predicate and the warning's first bullet are written out inline, as
  the eighth in-place copy of each; a source comment records why and cites
  issue #246 for the consolidation.
- The plain route raises `surveycore_warning_nonprob_srs_conversion` before the
  conversion call. Three bullets, each built with `paste0()` one fragment per
  source line, and `class=` on the `cli::cli_warn()`.
- `as_tbl_svy()` starts accepting both shapes with no body edit. Its guard
  already tested `survey_base`, which a `survey_nonprob` design inherits, so it
  only ever failed inside `as_svydesign()`. Verified byte-identical body.
- Three new `@section` blocks on `as_svydesign()`, of 17, 17 and 13 lines for
  47: the non-probability design and what the round trip loses, the degrees of
  freedom on both shapes with both qualifiers, and the filtered design's
  domain. Section 2 points at `vignette("surveycore-vs-survey")`.

## Notes for tester

Five neutral facts, each of which would otherwise cost a reader time.

1. **`survey::weights()` is not callable.** The plan's AC-1 writes the
   replicate-column assertion as
   `ncol(survey::weights(converted, "analysis"))`. That errors with
   `'weights' is not an exported object from 'namespace:survey'` — `weights` is
   a base S3 generic and `survey` registers a method for it rather than
   exporting one. The block asserts
   `ncol(stats::weights(sv, "analysis"))` instead, which dispatches to
   `weights.svyrep.design` and observes the same thing.

2. **`expect_no_warning(..., class =)` does not swallow other warnings.** In
   B-7's plain-shape half the CN-3 warning propagates past the inner
   expectation, so it is nested inside an
   `expect_warning(..., class = "surveycore_warning_nonprob_srs_conversion")`.
   Without that the suite's warning count rises by one. The inner expectation
   still asserts the absence it is there for.

3. **The `_snaps/conversion.md` diff is 19 insertions and 0 deletions.** E-3's
   block lands at the top of the file rather than at the end, because testthat
   writes snapshots in test-execution order and the E-1 block sits at line 281.
   It is still a pure insertion: no existing line is deleted or modified, and
   all eight pre-existing blocks are byte-identical.

4. **A full `devtools::test()` run leaves 30 `_snaps/*.md` files showing as
   modified in `git status` with no content change.** Their blob hashes equal
   HEAD's, `git diff` is empty, and `git add` on all of them stages nothing. It
   is a stale stat cache, not a content diff — the tail of issue #161.
   `git add tests/testthat/_snaps/` clears the display.

5. **The degrees-of-freedom figures in the new roxygen were measured on the
   test fixture, not carried over from a document.** `survey::degf()` on the
   40-row fixture answers 39 on the plain shape, 7 on the replicate shape with
   8 columns, 38 on the plain shape with one zero-weight row, and 7 on the
   replicate shape with the same zero weight. All four match the section's
   text.
