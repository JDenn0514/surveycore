## Summary

- `rho = NULL` is the fifth formal of `as_survey_replicate()`, after `type`
  and before `scale`.
- The `rho` rules run after every existing check, `.validate_rscales()`
  included. `type = "Fay"` with no `rho` aborts with
  `surveycore_error_fay_rho_missing`. An invalid `rho` aborts with
  `surveycore_error_fay_rho_invalid`, with the `rho_cls` and `rho_txt`
  bindings of spec §III.
- A valid Fay `rho` is stored as `as.double(unname(rho))`. The scale is
  `1 / (n_rep * (1 - rho)^2)`, and a supplied `scale` is discarded with no
  condition. The default-scale switch has no `Fay` entry.
- `rho` with any other type raises `surveycore_warning_rho_ignored`, and the
  design stores `rho = NULL`. The `@variables` list carries `rho` between
  `mse` and `visible_vars` for every type.
- Roxygen: `@param rho` after `@param type`, with the layout sentence and the
  `rho = 0` sentence. The `@param scale` and `@param type` edits are made,
  and the Fay example is the last `@examples` block. `@references` is not
  changed (PR 2).
