## Summary

- `survey_base` gains its first validator. It reads `SURVEYCORE_DOMAIN_COL`
  from `names(self@data)` first and returns on the common path; when the
  column is present and `is.logical()` is `FALSE` it aborts with
  `surveycore_error_domain_not_logical`. The four concrete classes carry no
  new check — one body on the parent delivers the abort on all four.
- The error message is the spec's, byte for byte against row 103 of
  `plans/error-messages.md`: an `"x"` bullet naming the column and the class
  it holds, an `"i"` bullet naming `surveytidy::filter()` as the producer, no
  `"v"` bullet.
- New fixture `set_domain_marker(design, type, mask = NULL)` in
  `tests/testthat/helper-test-data.R` writes the marker column in any of six
  storage types — logical, integer, double, character, factor, list. It writes
  through `new_data[SURVEYCORE_DOMAIN_COL] <- list(value)`, which takes an
  atomic vector and a list alike, so one line covers all six.
- Four new reject-path blocks in `tests/testthat/test-s7-classes.R`, one per
  concrete class, each `expect_error(class = ...)` with no snapshot.
- Four existing blocks repaired. The two quantiles blocks drop their
  `as.integer()` wrapper and keep every assertion. The conversion loop keeps
  all five types: the logical iteration keeps its three expectations, the
  other four now assert the error class at the write. The factor block now
  asserts the error class at the write, and the comment that stated the old
  premise is replaced.
