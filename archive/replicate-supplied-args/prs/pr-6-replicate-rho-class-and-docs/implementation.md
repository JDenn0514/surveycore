## Vignette change (decision S-1)
`vignettes/creating-survey-objects.Rmd` §3.4 "The `scale` and `rscales`
arguments" only. It now states:
1. `type = "JKn"` requires `rscales`, and a call with no `rscales` is refused.
2. For `"BRR"`, `"JK2"`, `"ACS"` and `"successive-difference"` a supplied
   `scale` is ignored, and for `"JK2"`, `"ACS"` and `"successive-difference"`
   a supplied `rscales` is ignored. surveycore drops the value, uses the
   type's own value, and warns with
   `surveycore_warning_replicate_arg_ignored`. For `"Fay"` the scale always
   comes from `rho`.
3. For the other types, the existing advice stays: override `scale` or
   `rscales` only when the codebook specifies custom values.

No code chunk was added. Nothing else in the vignette changed. The vignette
rendered with `rmarkdown::render()` to a scratch directory outside the
worktree; no generated file is in the worktree.
