### Tasks

1. Replace the raking oracle test (TDD)
   - **Note**: After PR 1 merges, lines 631–716 cited below will shift. Re-verify the exact line range of the old raking oracle block (look for the block referencing `sv_cal1`, `sv_raked`, `cd1`, `cd2`, `pop_gender`, `pop_age`) before deleting it.
   - Write the new failing test shell: `test_that("calibration-adjusted SE from get_means() matches survey::calibrate(calfun = 'raking') oracle [raking, nhanes]", ...)` — the test must fail before step 2 because the old oracle (two-sequential-calibrate) produces a different SE than `survey::calibrate(calfun = "raking")`
   - Implement the new oracle:
     - Filter `nhanes_2017` to `ridstatr == 2` and `wtmec2yr > 0`
     - Create factor variables `riagendr_f` and `age_group` (four-level cut on `ridageyr`)
     - Build the `survey::svydesign()` reference object
     - Call `survey::rake()` on the reference to obtain final converged IPF weights (use `survey::rake()` for weight computation, consistent with the existing code's data-generating process; the oracle SE comes from `survey::calibrate(calfun = "raking")`, not `survey::rake()`)
     - Build the combined model matrix: `X_gender` (n × 2 indicator for `riagendr_f`), `X_age` (n × 4 indicator for `age_group`); column-bind with the last column of `X_age` dropped: `cbind(X_gender, X_age[, -4L])`; this is the combined n × 5 matrix (2 + 4 − 1 drops)
     - Compute g-weights as `weights(sv_raked) / nhanes_sub$wtmec2yr` (final converged IPF weights from `survey::rake()` divided by base weights)
     - Construct a single `as_caldata(nhanes_sub$wtmec2yr, g, combined_mm)` element
     - Build the `survey::calibrate(sv_design, formula = combined_formula, population = combined_pop, calfun = "raking")` oracle, where `combined_formula` and `combined_pop` encode the same combined indicator matrix; extract oracle SE via `survey::SE(survey::svymean(~bpxsy1, sv_raked_oracle, na.rm = TRUE))`
     - Assign single caldata to `sc_design@calibration <- list(cd)` and assert `get_means(sc_design, bpxsy1)$se` equals oracle SE within 1e-8
   - Delete the old two-sequential-calibrate test block (lines 631–716)
   - Confirm the new test passes
